# FunnyFrench – Playful Text Transformer

FunnyFrench turns *your own text* into a light-hearted, mock-French accent. Runs entirely on-device. No accounts, no tracking.

## How it works
- Tokenizes your input with Apple’s NaturalLanguage framework
- Applies a set of reversible substitutions ("the" → "le/la/oy/ze", etc.)
- Shuffles adjective/noun order for comedic flavor

## Privacy
- We do not collect, store, or transmit your text. Processing is local on your device.

## Content
- This app only transforms *user-provided* text. It does not target a protected class and offers no built-in content. It’s a playful filter comparable to a meme caption tool.
